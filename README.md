# 洞烛万象 · KANG VISION — 安装包下载

本仓库**只存放编译好的安装包**，源代码在私有仓库中。

## 下载

打开右侧 **Releases** → 选最新版本 → 下载 `VisionMeasurement_*_win64.exe`

或直接点：
https://github.com/kang8888866-max/Vision-APP-Releases/releases/latest

## 使用

1. 下载 exe（约 125 MB），放在任意文件夹
2. 双击运行。首次启动会慢 3~5 秒（要解压）
3. Windows 若提示"已保护你的电脑" → 更多信息 → 仍要运行（未做代码签名，正常）
4. 弹出激活窗口 → 把机器码发给作者 → 粘贴激活码 → 激活成功，以后不再询问
